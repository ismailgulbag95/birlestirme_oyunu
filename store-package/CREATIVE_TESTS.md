# Store creative test plan

Test one main variable at a time. Use the same audience and localized listing while the experiment is live; allow each treatment to collect enough impressions for the store's confidence/readout before choosing a winner.

## Test 1 — Icon hook

- **A (recommended baseline):** open Curio aperture with amber diamond on midnight blue (`brand-icon-a-play-512.png`).
- **B:** two colored inputs meeting one amber result (`brand-icon-b-play-512.png`).
- **Question:** does the ownable curiosity mark or the more literal combination cue earn more listing visits?
- **Primary metric:** store experiment's install-click/conversion readout. Check product-page visits and downstream install conversion in available analytics as a quality guardrail.
- **Decision:** keep A unless B's CTR improvement is clear and install conversion does not fall.

## Test 2 — First screenshot hook

- **A:** four starting elements and full workshop (`01-start`).
- **B:** two elements already on the glowing workbench (`02-combine`).
- **Question:** does starting-state clarity or immediate interaction curiosity bring more installs?
- **Primary metric:** product-page view → install conversion; use CTR only if the store exposes the asset impression path.
- **Keep:** screenshots 2–3 and all text identical during the test.

## Test 3 — Feature graphic (Google Play)

- **A:** clear brand plus real workshop crop.
- **B:** clear gameplay promise with larger starting-element imagery from real game assets.
- **Question:** which visual previews the experience more clearly in placements that show the graphic?
- **Do not:** change metadata and graphics in the same treatment.

## Test 4 — Localized short description (Google Play)

Run after publication and once there is enough traffic. Use a localized text experiment and change only the short description.

| Locale | A — clarity first | B — collection proof |
|---|---|---|
| English | Mix Fire, Water, Earth & Air to discover new recipes in a 3D alchemy workshop. | Explore 92 Classic discoveries by mixing elements in a 3D alchemy workshop. |
| Turkish | Ateş, Su, Toprak ve Havayı birleştir; 3D simya atölyende yeni tarifler keşfet. | 3D simya atölyende elementleri birleştir, Klasik koleksiyonda 92 keşfi tamamla. |

Alternate title candidates are `Curio Alchemy: Mix & Discover` (29/30) and `Curio Simya: Birleştirme` (24/30). Use the selected title as listing metadata; the current Play experiment flow tests descriptions and graphics, not app names.

Google Play's primary experiment metric is unique user install clicks; rely on the console's confidence and sample-size readout instead of stopping early.

## Apple product page optimization

Start with the icon test, then screenshot-first-frame test. Apple allows up to three treatments. Add the test icon to the release binary as required by App Store Connect, and only run after the page is eligible. Avoid multiple simultaneous changes that make the result hard to interpret.

## Reading the result

Review impressions, product-page visits, installs, and install conversion together. A higher CTR that brings the wrong audience can lower install conversion. After a store win, observe early retention before rolling the asset across other locales. Do not promise an uplift before a real experiment.
